# 运作命令要素边界与默认值（刹车文档）

> 用途：运作命令生成智能体知识库约束文档。生成节点、通用问答、澄清问询一律以本文档为准；与模型常识/其他文档冲突时，以本文档为准。
> 依据：33份《2025年N号运作命令》全文逐字统计（语料2025_md/），重点对标 2025年29号（国庆中秋）、2025年33号（跨年延时）。

## 1. 命令正文只有四章（或三章），没有其他要素

- 变体A（28/33）：一、运作时间段 → 二、ATS系统中留存运行图 → 三、调图风险 → 四、注意事项
- 变体B（5/33）：一、运作时间段 → 二、ATS系统中留存运行图 → 三、注意事项
- 判定：**调图风险默认无（走变体B）**；用户明确给出风险项点才开风险章（变体A）。

各章只写：一章=生效句+8线表格；二章=留存固定句式+留存图号表；三章（如有）=调图项点句+风险表（线路|乘客服务|行车组织|生产运作）；末章=注意事项条目（（一）（二）…中文数字编号）。

## 2. 不在正文的要素——禁止问询、禁止生成

以下要素**不属于命令正文**，生成时不出现、澄清时不问询。用户问及则答"不属命令正文，人工补"：

| 要素 | 真实归属 | 处理方式 |
|---|---|---|
| 签批/审批/发布要求 | 发布流程 | 人工，流程外 |
| 发文字号〔20XX〕N号 | 红头通知层 | 永远占位符，人工补（文号=公司全年发文流水号，与命令号无函数关系：1号命令=文号4，33号命令=文号338） |
| 主送/抄送/附件清单/落款/成文日期 | 红头通知层 | 人工补（成文日期=生效日前1-3天） |
| 命令类型/命令目的/调图缘由 | 红头通知正文段 | 通知层一句话，不进命令正文 |
| 安全与应急要求/提出人 | 出处不明（不在命令正文；33份命令及G33-2020提取文本中均零出现） | 不属本智能体生成范围，禁止编造；用户需要时人工补或先确认依据 |
| 生效期起止时刻 | 不存在 | 33/33命令不写起止时刻，只写每日运营时间 |

每个发布物=红头通知（主件）+ 命令正文（附件1）+ 运行图（附件2）。本智能体只生成附件1。

## 3. 默认值表——能默认的一律不问

| 字段 | 默认值 | 依据 |
|---|---|---|
| 生效日期 | 用户提供（必问项之一） | — |
| 生效期结束 | 无结束日期，固定句"{YYYY}年{M}月{D}日起至另有通知时止" | 33/33首句完全一致 |
| 起止时刻 | 不写 | 见第2节 |
| 运营时间 | 按图号从检索到的范本反查（29号表44条全可查）；查不到才【待补】 | 一章表格"运营时间"列，跨夜写"次日HH:MM" |
| 运作时间段列 | 生效日期+"起"+时段条件（逢工作日/逢周末/全天/日期段如"10月1日-5日"），一段一行、一段一图号 | 29号一章按图号分6-7行/线 |
| 执行运行图 | 用户提供（按线给）；未给的线写"【沿用现行图，请核实】"，不得编造 | — |
| 备用车安排 | 图定备车 | 33/33常规口径 |
| ATS留存 | 基线+本期变更（基线=ATS留存基线_2025年33号.json） | 二章全量清单非模型生成 |
| 调图风险 | 默认无（三章变体） | 5/33为三章变体 |
| 注意事项 | 固定套话14条全继承 + 条件套话按需 + 本期新写0-5条 | 频次统计（≥20次共14条），33份中10期新写为0条 |
| 移出ATS部门口径 | 自动化中心（2025年5月架构调整后） | 20份"各运营中心"/10份"自动化中心"，现行=自动化中心 |
| 客流反馈电话 | 66931882（2025年16号起切换；1-15号旧值66931892不再新写） | 语料逐字统计 |
| 发文字号 | 占位符，永不编造 | 见第2节 |

固定套话来源=历史范本"注意事项"章直接继承（轧道车限速、王家港折返、3号线严禁早发晚发、青岛站折返、8号线换乘联动、车次标注、开站时间、客流反馈等），与本期需求冲突的删除。**不需要单独建规则知识库——默认值的来源就是语料范本本身。**

## 4. 问询门禁：最多4项

只允许问以下4项，其余要素一律默认继承、禁止问询：

1. 生效日期（如"2026年10月1日起至另有通知时止"）
2. 各线路执行图号（如"1号线《Z01149》、3号线《T03061》"；Z=常规图、T=节假日/特殊图、Y=备用，前2位线路代号 01/02/03/04/06/08/11/13）
3. 调图项点描述（如"节假日图切换、1号线延时30分钟"）
4. 风险项点（有/无）——决定三章/四章结构

问询输出格式固定为《编制信息确认单》，并注明"已提供的信息将自动保留，无需重复"。超出这4项的提问（签批、安全应急、命令类型、时刻等）一律视为越界，删去。

## 5. 范本命中规则（检索）

| 需求类型 | 命中范本 |
|---|---|
| 节假日（国庆中秋/春节/五一/节假日图切换） | 2025年29号 |
| 跨年/延时运营 | 2025年33号 |
| 常规调图/微调/延续 | 普通号（如2025年10号） |

- 检索query须含"运作命令"关键词，防止命中管理规定或运行图说明；
- 运营时间反查只认命中国范本的表格——范本错了（如国庆需求命中跨年33号）运营时间全错，需人工核对图号时刻表；
- 29号文档入库时应带标注：国庆、中秋、节假日、范本。
