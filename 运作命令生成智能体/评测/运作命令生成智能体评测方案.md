## 二、画布关键路径（v2.0 实测拓扑）

开始 → 历史运作命令检索(RetrieverV2) → RAG重排器-1 → C1 槽位抽取与校验 → I1 槽位齐？
- 槽位缺 → C2 确认单组装 → C3 Markdown确定性组装 → C4 终检与校对要点 → 结束（澄清问询输出）
- 槽位齐 → L1 注意事项条目生成(OnlineLLM) → C3 → C4 → I2 Word导出开关？
  - 否 → 结束（命令正文）
  - 是 → Word文档生成(MCP) → Word地址提取(OnlineLLM) → 结束

## 四、指标与权重

| 指标 | 类别 | 权重 | 说明 |
|---|---|---|---|
| 端到端任务成功率 | 结果类（平台自动采集） | 0.35 | 命令正文结构完整、章节符合变体A/B判定 |
| 答案相关性 | 结果类 | 0.30 | 输出与query意图匹配，澄清场景不生成正文 |
| 关键词命中 | 结果类 | 0.20 | impWords 按用例核对（运作时间段/ATS/留存等） |
| 意图与路径正确率 | 过程类 | 0.15 | expectedPath 命中，I1/I2 分流正确 |

（结果类3项已选满；过程类选1项——路径分流是本智能体核心风险点。权重可按平台配置界面微调。）

## 五、导入前待确认项

- 智能体ID（平台侧）
- 调用密钥（平台侧）
- I2 Word导出开关的默认值口径（用例默认不导出Word；如平台默认开，N0001-04需补Word断言）
- L1 节点当前报错"Unexpected keys: ['slots','sample_text']"——导入前需修复上游变量绑定，否则N0001/03/04端到端会失败（2026-11-02截图实况）
