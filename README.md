# Dify 系列 AI 智能体

本仓库集中管理基于 Dify / 极视角等平台研发的各类 AI 智能体、MCP 服务与配套工具，主要面向轨道交通运营生产场景（客流分析、运行图编制、运输计划、运营组织保障等）。

## 使用方式

1. **Dify 应用**：在 Dify 控制台选择「导入 DSL 文件」，上传对应目录下的 `.json` 文件即可。
2. **MCP 服务**：进入对应目录，参考其中的 README 或设计文档，使用 Python 启动 `server.py`。

## 分支与标签规范

### 分支

| 分支 | 用途 | 命名示例 |
| --- | --- | --- |
| `main` | 稳定版本，只接收测试通过的合并 | — |
| `feat/<编号>-<简述>` | 单个智能体的功能开发 / 大版本迭代 | `feat/YSJQ-0005-周报优化` |
| `fix/<编号>-<简述>` | 问题修复 | `fix/查重系统-超时` |

开发流程：从 `main` 切出功能分支 → 开发并提交 → 合并回 `main` → 删除功能分支。

```bash
git checkout -b feat/YSJQ-0005-周报优化
# …开发、提交…
git checkout main
git merge feat/YSJQ-0005-周报优化
git branch -d feat/YSJQ-0005-周报优化
```

### 标签（发布版本）

某个智能体发布正式版本时打标签，格式：`<编号>-v<主版本>.<次版本>[.<修订号>]`

| 标签示例 | 含义 |
| --- | --- |
| `YSJQ-0005-v1.0` | 客流分析智能体 1.0 正式发布 |
| `YSJQ-0005-v1.1` | 功能小幅迭代 |
| `YSJQ-0005-v1.1.1` | 仅修复问题的补丁版本 |
| `MCP-查重-v2.0` | 查重系统 MCP 2.0 |

```bash
# 打标签（带说明）并推送
git tag -a YSJQ-0005-v1.1 -m "客流分析：新增周报自动生成"
git push origin YSJQ-0005-v1.1

# 查看 / 检出历史版本
git tag -l
git checkout YSJQ-0005-v1.0
```

### 提交信息前缀

| 前缀 | 用途 |
| --- | --- |
| `feat:` | 新功能 |
| `fix:` | 问题修复 |
| `docs:` | 文档变更 |
| `refactor:` | 结构调整（无功能变化） |
| `chore:` | 杂项（配置、依赖等） |
