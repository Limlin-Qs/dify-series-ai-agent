# Dify 系列 AI 智能体

本仓库集中管理基于 Dify / 极视角等平台研发的各类 AI 智能体、MCP 服务与配套工具，主要面向轨道交通运营生产场景（客流分析、运行图编制、运输计划、运营组织保障等）。

## 目录结构

### 运输生产系列智能体（YSJQ）

| 目录 | 说明 |
| --- | --- |
| `YSJQ-0001_沿线活动组织保障智能体` | 沿线活动客流预测与组织保障报告生成 |
| `YSJQ-0002_节假日运营组织` | 节假日运营组织方案编制与报告生成 |
| `YSJQ-0003_新线运营组织保障` | 新线开通运营组织方案编制 |
| `YSJQ-0004_运行图编制智能体` | 列车运行图编制辅助 |
| `YSJQ-0005_客流分析` | 客流分析及周报自动生成 |
| `YSJQ-0007_运输计划生成智能体` | 运输计划配置维护与生成 |
| `YSJQ-0008_运行图评估` | 运行图评估分析与报告生成 |
| `YSJQ-0009_多网融合智能体` | 多网融合分析与报告生成 |
| `YSJQ-子智能体与工具` | 公共子智能体与工具（文档读取/导出、天气查询、LangGraph 工作流等） |
| `MS_DW_002 多源数据融合` | 多源数据融合智能体及配套数据 |

各目录下的 `.json` 文件一般为 Dify 应用 / 工作流的导出文件，可直接在 Dify 中导入使用；部分目录附有 drawio 流程图、测试数据与示例报告。

## 使用方式

1. **Dify 应用**：在 Dify 控制台选择「导入 DSL 文件」，上传对应目录下的 `.json` 文件即可。
2. **MCP 服务**：进入对应目录，参考其中的 README 或设计文档，使用 Python 启动 `server.py`。
