# 2026-11-05 考试复盘 — 绩效统计题没调通

## 一、发生了什么

- 考题：对 CSV（17人35条加分记录，混6条错误）做数值统计分析，按结果生成六章报告。
- 现象：按大模型建议配置各节点，没调通。
- 准备偏差：考前工具箱主线押在「表格→知识库→检索问答」（防汛/一线声音族）；数值计算+报告族只此一套，恰好考了。

## 二、根因（按权重排序）

1. **路线错误：数值计算交给了大模型节点。** 本题验收要求与标准答案完全一致；LLM 算总分/排名/占比必然漂。确定性计算（校验、求和、封顶、排名、占比）必须全部在 Code 节点完成，LLM 只做第六章改进建议这类文字段。
2. **准备终点错了：产出是"资料"不是"彩排"。** 工具箱读过眼 ≠ 每类题有一条跑通的链路。缺最后一步：把典型题在平台上真跑一遍。
3. **Code 节点铁律没吃透**（技能里都有，考场没用上）：
   - import/辅助函数必须写在 def main 里；顶层只能有一个 main
   - 沙箱无 pandas，CSV 只能作为 string 传入（知识库检索/重排输出，或直接粘贴全文），不能在代码里开文件
   - 输入参数名必须与节点声明逐一对应并有类型标注；输出变量名必须纯英文
   - LLM 节点运行时只认 query 输入键，其他值用提示词宏 {{#节点ID.输出#}} 引用
   - 提示词要双镜像（嵌套+平铺两处都写），否则导入后提示词框空白

## 三、正确链路（已在本地验证与标准答案逐项一致）

开始(query:string)
→ [CSV入知识库，RetrieverV2 检索 → Reranker join 成全文]（或开始节点直接吃粘贴的CSV全文）
→ Code「校验+计算+章节一~五拼装」：main(query, docs) → report_md / ranking_table / removed_table / stats / chap6_packet
→ LLM「第六章改进建议」：query 绑 chap6_packet，提示词给角色+字数，只写建议正文
→ Code「拼终稿」：report_md + 建议正文 → final_md
→ 结束

产物（本目录）：
- 绩效统计_代码节点.py — 平台版 main，TC1~TC4 全过（6条剔除含行号、周涛封顶、平均89.38、等级3/3/11/0、赵敏86分追问）
- 绩效分析报告_生成成品.md — 代码直接生成的报告，与参考答案样例逐项一致

## 四、下次考试怎么准备

1. 按题型族准备"每族一条已跑通链路"：检索问答族 / 数值计算+报告族 / 文档审查族，各真跑一遍，不是读资料。
2. 拿到题先分类：数字要精确 → Code 节点算；文字要生成 → LLM 写。验收标准写"完全一致"的，LLM 不许碰数字。
3. 开考5分钟环境核查（工具箱第九节）保留。
