## 一、数据摸底结论（已实际验证）

⚠️ 注意：考试说明称"10个Sheet"，实际提供的文件各只有 1 个 Sheet。**若考场上拿到的真是 10 个 Sheet 的版本（总表1个+9条线路各1个），入库时要全部上传，别漏。**

### ⚠️ 三个数据陷阱
1. **TC2 大流量排水泵**：明细表"2号线辽阳东车辆段-车站维保部"行的**数值列=0**，但**详情列**写了"柴油抽水泵（140m³）1台 + 大流量便携潜水泵（150m³）1台"。预期答案"大流量排水泵2台"取自**详情列**。智能体必须读取详情列，不能只看数值列。
2. **测试用例文档有错别字**（"防雨蓬布"应为"防雨篷布"、"防淦挡杷"应为"新型防淹挡板"），以 Excel 原始数据为准。
3. **TC3 口径**：明细行级（站点×部门）沙袋<100 的有 339 条（另有 222 行为 0）；**聚合到站点后只有 18 个站点**。预期输出要求含"所属部门"，合理答法是**按站点聚合列出 18 个站点**（附涉及部门），而非罗列几百行。

## 二、知识库构建方案（20分）

1. **统一数据结构后再入库**（考试说明明示的关键点）：把两个 Excel 清洗为统一格式 `线路/中心 → 车站/段/场 → 部门 → 物资类型 → 数量 → 详情备注`。
2. **分块策略**：
   - 表格类数据切忌大块混切——一条记录（线路+站点+部门+各物资数量）是一个完整语义单元；
   - 若平台支持按行/按记录解析表格，优先保留行完整性；
   - 分段后必须**保留归属信息**（每条记录带线路名、站点名），否则召回的碎片无法定位来源。
3. **入库后必做召回验证**：用 TC1-TC3 的问题各试一次，确认能召回正确记录，并抽查总表与明细表数字互相印证。
4. 上传 ≥3 份文档的硬性要求：本题只有两个 Excel，可**清洗后按用途拆分**（如"总表"一份 + "明细表"按线路拆或整份 + 一份物资别名/口径说明文档），凑足数量且提升召回精度。

## 三、智能体流程设计（意图识别20分 + 检索25分 + 聚合15分）

### 最小可运行链路
```
开始 → 意图识别（模型节点）→ 条件分支 → [汇总查询 / 明细查询 / 缺货预警] → 知识库检索 → 代码节点（聚合计算）→ 模型节点（组织回答）→ 输出
                                                                                  ↘ 拒答分支（超出知识库范围）
```

### 必须有分支（线性流程最高只能拿75-89分档）
- **意图分支**：汇总（线路级）/ 明细（站点级）/ 预警（阈值筛选）/ 调配（备选）/ 拒答，至少 3+1 条；
- **拒答分支**：问题与防汛物资无关或数据不存在时，明确拒答，不编造（评分标准明示"未知数据不编造"）。

### 分工原则（来自 skill 核心规则）
- **代码节点干确定性的事**：数值筛选（<100）、求和、排序、缺口计算（100−库存）、千分位格式化——**不让模型口算**；
- **模型节点干语义的事**：意图识别、别名归一、自然语言组织回答；
- 模型输入控制在 12-16k tokens 以内，代码节点先做筛选再传候选数据。

### 别名识别（考试说明第4条明示考点）
| 用户口语 | 应归一到 |
|---|---|
| 沙袋 | 防汛沙袋、吸水膨胀袋（可分别列出并汇总） |
| 水泵 | 潜水泵、自吸泵、大流量排水泵 |
| 挡板 | 防洪挡板、L型轻型防洪挡板、新型防淹挡板 |

### 输出格式（考试说明硬性要求，四段式）
```
【回答正文】自然语言主回答
【数据来源】哪个表/哪条记录
【计算过程】聚合步骤（如：明细表1号线168条记录沙袋求和=23,136，与总表一致）
【相关推荐】如"是否查看1号线各站点沙袋明细分布"
```
数值加**千分位分隔**（23,136）、带**完整单位**（个/台/块/组）。

## 四、提示词设计（按评分表四要素：角色/任务/约束/示例）

骨架模板：

```
# 角色
你是地铁防汛物资查询助手，服务于防汛物资管理人员。

# 任务
根据用户自然语言问题，从知识库检索物资库存数据并回答：
1. 站点/部门级物资明细查询；2. 线路/中心级物资汇总查询；3. 低于安全阈值的缺货预警。

# 约束
- 只使用知识库检索到的数据，禁止编造任何数字；检索不到就明确说明"未查询到相关数据"。
- 别名归一："沙袋"含防汛沙袋和吸水膨胀袋；"水泵"含潜水泵、自吸泵、大流量排水泵。
- 大流量排水泵数量以"详情"列描述为准（数值列可能为0）。
- 数值用千分位分隔，单位完整；聚合计算展示过程。
- 输出固定四段：【回答正文】【数据来源】【计算过程】【相关推荐】。
- 与防汛物资无关的问题，礼貌拒答并引导回物资查询。

# 示例
问：1号线有多少防汛沙袋和潜水泵？
答：【回答正文】1号线共有防汛沙袋23,136个、潜水泵36台……
```

## 五、测试验证方案（必须留痕，90+分硬要求）

| 用例 | 输入 | 通过标准（自查清单） |
|---|---|---|
| TC1 汇总 | 1号线有多少防汛沙袋和潜水泵 | 答出 **23,136个 / 36台**；注明来源总表；补充主要站点分布（东郭庄停车场、东郭庄站等） |
| TC2 明细 | 2号线辽阳东车辆段有哪些防汛物资 | 车辆维保部 沙袋956/篷布8/潜水泵5；工电维保部 107/1/5；车站维保部 50/**大流量排水泵2台（看详情列）**/潜水泵2/自吸泵2 |
| TC3 预警 | 哪些站点防汛沙袋不足100个 | 按站点聚合共 **18 个站点**，含站点名/线路/库存/缺口(100−库存)/部门 |
| 加试 拒答 | "今天天气怎么样" | 触发拒答分支，不编造 |
| 加试 别名 | "1号线有多少水泵" | 归一为潜水泵36台+自吸泵83台+大流量排水泵9台，分别列出并汇总 |

每个用例记录：输入、实际输出、是否通过、调整了哪里 → 整理成测试报告或截图提交。

## 六、2小时时间分配（按考试说明建议）

| 环节 | 时长 | 关键动作 |
|---|---|---|
| 知识库 | 25 min | 清洗统一格式 → 上传 → 分块配置 → 召回验证 |
| 流程搭建 | 65 min | 意图识别 + 分支 + 检索 + 代码聚合 + 输出，先跑通最小链路再补分支 |
| 提示词 | 20 min | 按四要素模板填充，重点写别名和拒答 |
