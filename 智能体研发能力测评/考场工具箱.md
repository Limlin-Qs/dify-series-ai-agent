# 考场工具箱

> 用法：进考场后从第一节开始照着做。配合各考试包目录下的《数据准备指南.md》使用。
> 原则一句话：**确定性的活给 Excel 和代码节点，语义的活给模型，你负责描述需求和核对结果。**

---

## 一、开考 5 分钟环境核查清单（先做，别跳）

1. **代码节点**：有没有？语言是 Python 还是 JS？贴 `return {"a": 1}` 试跑，看清输入输出变量怎么配置。
2. **沙箱限制**：`import json` 一定行；pandas/openpyxl/requests **默认没有**，代码只用标准库写。
3. **本机 Excel/WPS**：能正常打开 xlsx（数据清洗全靠它）。
4. **文件上传**：知识库支持哪些格式（xlsx/csv/md/txt/pdf）、单文件大小上限——决定要不要拆文件。
5. **MCP 工具**：节假日日历等试调一次，确认覆盖 2026 年、看清返回格式。**没验证过的工具不写进主流程关键路径**。
6. **模型对话/调试窗口**：确认有地方贴考试助手提示词，随问随用。

## 二、应用类型选型（30 秒判断）

```
一次性输入 → 跑一遍 → 吐结果？     是 → 工作流
连续提问/追问/拒答/多轮？          是 → 对话流（拿不准就选它，能装下单次逻辑）
开放任务+自主调工具？                   → 智能对话智能体（考试基本用不上）
```

| 题目 | 信号词 | 选型 |
|---|---|---|
| 一线声音 | 语音文本→JSON表单，一次性 | 工作流 |
| 供应商审查 | 档案→审查意见书，一次性 | 工作流 |
| 施工计划 | 审核+规章问答"在同一智能体或关联对话" | 对话流（审核/问答两分支） |
| 防汛物资 | 连续查询+5意图+拒答 | 对话流 |
| 防汛风险 | 连续对比提问+5意图 | 对话流 |
| 车辆均衡修 | 多意图查询（里程/判定/工单/批量） | 对话流 |

**为什么不用纯智能体型**：评分表"流程节点搭建 30 分"要求看得见的节点编排和条件分支，纯智能体型没节点可评。

## 三、考试助手系统提示词（贴进对话窗口即可用）

```text
# Role
你是考试现场的编程与提示词助手，服务于智能体搭建实操考试。

# 平台约束（最高优先级）
- 代码只运行在受限沙箱：仅 Python 3 标准库，禁止联网、禁止 pip、禁止第三方库（无 pandas/numpy/openpyxl）。
- 代码节点约定：输入通过变量字典传入，输出必须是 dict，只返回 JSON 可序列化的值。
- 不涉及沙箱外文件读写；数据处理脚本如需读 Excel，明确说明"需在平台外先行处理"并改用纯文本/CSV 方案。

# 能力范围（仅四类，其他需求礼貌拒绝）
1. 代码节点开发：数据清洗、聚合计算、阈值筛选、JSON 校验、字符串处理；先列 3 步思路再给完整可运行代码，复杂逻辑加注释。
2. 流程构建建议：用"节点A→节点B"的纯文本描述，不给平台无关的架构理论。
3. 提示词生成：严格按四要素【角色/任务/约束/示例】生成，必含拒答约束和"禁止编造数据"条款。
4. 错误诊断：我贴报错信息，你先给原因定位，再给最小修改方案。

# 输出格式
- 简洁、直接，不寒暄；代码块标注语言；每次回答不超过必要的篇幅。
```

还能让它干的三件事：① 出**召回验证问题**（知识库上传后让它根据语料出 5 题）；② **输出核对**（贴智能体实际输出，对照预期答案逐项找茬）；③ 写 **Excel 公式**（用大白话描述需求）。

## 四、大模型参数速查

| 节点用途 | 温度 | 说明 |
|---|---|---|
| 意图识别/实体提取/JSON 输出 | **0 ~ 0.2** | 输出要被程序解析，必须稳定 |
| 规则比对/风险判定/数据核对 | **0 ~ 0.3** | 严格按阈值，不许自由发挥 |
| 自然语言回答组织 | **0.5 ~ 0.8**（或默认） | 数据已由代码节点算好，只管通顺 |

- 温度和 Top P **只调一个**（调温度，Top P 默认）。
- 存在/频率惩罚**平时不动**，模型复读时频率惩罚加 0.3~0.6。
- 最大标记**宁大勿小**：报告类 2000~4000，意图/分类类 200~500（给小了 JSON 被截断）。
- 判断标准一句话：**输出给程序读→低温；给人读→常温。**

## 五、JSON 接力链条（意图识别题的骨架，背下来）

```
模型节点（输出JSON文本） → 代码节点（json.loads解析+清洗+拆字段）
→ 条件分支（读 intent 等字段分流） → 各分支检索/计算/模型节点
```

**关键认知**：模型吐出的 `{"intent": "summary"}` 只是**字符串**，必须经代码节点解析，下游才能按字段引用。

解析节点代码（直接抄）：

```python
import json

def main(llm_output: str) -> dict:
    text = llm_output.strip()
    # 去掉模型可能加的 ```json 围栏
    if text.startswith("```"):
        text = text.split("\n", 1)[-1].rsplit("```", 1)[0].strip()
    try:
        data = json.loads(text)
    except json.JSONDecodeError:
        # 兜底：解析失败走拒答，流程不崩（异常处理采分点）
        data = {"intent": "reject", "line": "", "station": "", "item": "", "threshold": ""}
    return {
        "intent":   data.get("intent", "reject"),
        "line":     data.get("line", ""),
        "station":  data.get("station", ""),
        "item":     data.get("item", ""),
        "threshold": data.get("threshold", ""),
    }
```

三个必防翻车点：
1. 提示词写明"只输出 JSON，不要解释、不要 ``` 标记" + 温度 0（双保险）；
2. 全角引号/冒号会导致 `json.loads` 报错——兜底分支必须有；
3. 别把整坨 JSON 塞给模型，只传它需要的字段。

## 六、代码节点三问 + 正确模板

判断一段代码能否进代码节点，三问全过才行：**只用标准库？不碰本地文件？数据从参数进、return dict 出？**

```python
import json

def main(input_text: str, threshold: int) -> dict:  # 参数 = 节点界面配置的输入变量
    data = json.loads(input_text)
    result = [x for x in data if x["qty"] < threshold]
    return {"matched": result, "count": len(result)}
```

⚠️ 桌面脚本（读写本地 Excel、用 pandas）**永远进不了代码节点**，那不是改几行的事，是两种东西。拆 Sheet/洗数据在 Excel 里做完再上传。

## 七、Excel 数据清洗速查（替代脚本，考场首选）

| 清洗任务 | 操作 | 用时 |
|---|---|---|
| 删表头/示例行 | 选中 → 右键删除 | 10秒 |
| 合并单元格空值继承 | 取消合并 → F5 定位"空值" → 输 `=↑` → **Ctrl+Enter** | 1分钟 |
| 换行符→空格 | Ctrl+H，查找框按 **Ctrl+J**，替换为输空格 | 30秒 |
| 取值归一（如"较小风险（直判）"） | Ctrl+H 直接替换 | 10秒 |
| 加等级数值列 | `=IF(E2="重大风险",4,IF(E2="较大风险",3,IF(E2="一般风险",2,1)))` 下拉 | 1分钟 |
| 按线路/类别拆文件 | 筛选 → 复制到新工作簿另存 | 每个30秒 |
| 千分位 | 右键 → 单元格格式 → 数值 → 勾千分位 | 10秒 |

**层级树展开全路径（一线声音题，Excel 唯一费劲的活）**：
表右加 6~8 列"父/祖父/曾祖…"，第一列 `=IFERROR(VLOOKUP(B2,A:C,3,0),"")`（用 parentId 查 name），下一列把查找值换成上一列结果，往右拖即逐层回溯；最后 `&"/"&` 拼全路径。写不动就让考试助手写公式，你照贴。

## 八、MCP 工具使用

| 工具 | 用在哪 | 注意 |
|---|---|---|
| 节假日日历 | 车辆题 TC3/TC5 日期与节假日判断 | 日期/星期判断**必须走工具或代码**，不让模型口算；先验证覆盖 2026 + 调休；不好使就回退到自制节假日 txt 入库 |
| json转md | 结构化结果转表格，回答更清晰 | 只排版不算数，计算先由代码节点完成 |
| md转doc | 审查意见书/报告产出 Word 交付物 | 模型先生成 Markdown，再接此工具 |

三条纪律：开考先盘点试调；工具结果作为变量传给模型时，提示词写明"以下数据来自XX工具，以此为准"；工具失败要有异常分支（拒答或降级），别让流程崩。

## 九、考场时间分配（2 小时通用节奏）

| 环节 | 时长 | 关键动作 |
|---|---|---|
| 环境核查 | 5 min | 照第一节清单过一遍 |
| 知识库 | 20 min | Excel 清洗 → 上传 → 分块/标签 → 用 TC 题面召回验证 |
| 流程搭建 | 60 min | 先跑通最小链路，再补意图分支和拒答分支 |
| 提示词 | 20 min | 四要素（角色/任务/约束/示例）+ 拒答 + 禁止编造 |
| 测试验证 | 30 min | 全用例跑一遍 + 拒答加测 + 截图留痕 |
| 缓冲 | 5 min | 提交前检查交付物清单 |

**救命原则**：先保证测试用例全部跑通（及格线通常是 2 个），再优化分支和提示词；任何一个环节卡壳超过 10 分钟就贴报错问考试助手，别死磕。
