# 01_供应商准入审查基础规则

> 来源文件：01_供应商准入审查基础规则.docx

供应商准入审查基础规则（通用版）

### 一、审查目的

本规则适用于公司所有新供应商准入的合规性审查，旨在识别供应商在资质、财务、业绩、交付、合规等方面的潜在风险，为采购决策提供标准化、可量化的依据。

### 二、红线规则（一票否决项）

以下情形直接判定为【不建议准入】，不进行后续的审查要点与判定标准里的维度评判：

规则0.1 - 营业执照已过期

- 判定：营业执照已过有效期且未完成续期

规则0.2 - 失信被执行人

- 判定：经"信用中国"或"中国执行信息公开网"查询，供应商或其法定代表人被列入失信被执行人名单

规则0.3 - 重大安全/质量事故

- 判定：近3年内发生过重大安全生产事故或重大产品质量事故

### 三、审查要点与判定标准

【审查维度一：主体资质】（权重建议：20%）

规则1.1 - 营业执照合法性

- 标准要求：营业执照在有效期内，且通过国家企业信用信息公示系统年度公示

- 判定标准：

· 已过期 → 【红线规则0.1，一票否决】

· 有效期剩余＜3个月 → 【中风险】（需在准入前完成续期）

· 有效期剩余≥3个月 → 【低风险】

规则1.2 - 统一社会信用代码校验

- 标准要求：统一社会信用代码真实有效，与营业执照一致

- 判定标准：

· 代码不存在或与执照不一致 → 【高风险】

· 一致 → 【低风险】

规则1.3 - 经营范围匹配度

- 标准要求：经营范围需覆盖本次采购的产品/服务类别

- 判定标准：

· 完全不覆盖 → 【高风险】

· 部分覆盖（有上级授权或分包协议） → 【中风险】

· 完全覆盖 → 【低风险】

规则1.4 - 行业资质许可

- 标准要求：行业需具备相应体系认证资质证书（如生产许可证、经营许可证、认证证书等）

- 判定标准：

· 法定资质完全缺失 或 证书已过期 → 【高风险】

· 有效期剩余＜6个月 → 【中风险】

· 有效且覆盖范围匹配 → 【低风险】

规则1.5 - 注册信息一致性

- 标准要求：注册地址、法定代表人、股东信息与工商登记一致

- 判定标准：

· 关键信息不一致 → 【中风险】

· 一致 → 【低风险】

【审查维度二：财务健康度】（权重建议：20%）

规则2.1 - 成立年限

- 标准要求：≥1年

- 判定标准（以绝对值判定）：

· ＜6个月 → 【高风险】

· 6个月-1年 → 【中风险】

· 达到标准要求 → 【低风险】

规则2.2 - 注册资本

- 标准要求：≥500万元

- 判定标准：

· 低于标准50%以上 → 【高风险】

· 低于标准20%-50% → 【中风险】

· 达到标准 → 【低风险】

规则2.3 - 资产负债率

- 标准要求：资产负债率≤70%

- 判定标准：

· ＞85% → 【高风险】

· 70%-85% → 【中风险】

· ≤70% → 【低风险】

规则2.4 - 纳税信用等级

- 标准要求：纳税信用等级为A级或B级

- 判定标准：

· C级或D级 → 【高风险】

· M级（新设立企业）或无纳税记录 → 【中风险】

· A级或B级 → 【低风险】

【审查维度三：业绩与能力】（权重建议：25%）

规则3.1 - 同类项目业绩

- 标准要求：近2年内有不少于3个同类项目合作案例

- 判定标准：

· 0个案例 → 【高风险】

· 1-2个案例 → 【中风险】

· ≥3个案例 → 【低风险】

规则3.2 - 产能与交付能力

- 标准要求：具备满足采购需求的产能规模和交付保障

- 判定标准：

· 产能明显不足或无交付保障方案 → 【高风险】

· 产能基本满足但无应急方案 → 【中风险】

· 产能充足且有交付保障承诺 → 【低风险】

【审查维度四：交付与服务能力】（权重建议：15%）

规则4.1 - 交付周期与准时率

- 标准要求：承诺交付周期满足采购需求，历史交付准时率≥90%

- 判定标准：

· 无法满足交付周期要求 → 【高风险】

· 历史准时率80%-90%或无法提供证明 → 【中风险】

· 满足要求且准时率≥90% → 【低风险】

规则4.2 - 售后服务能力

- 标准要求：具备完善的售后服务体系（响应时间、退换货政策、质保条款）

- 判定标准：

· 无售后服务方案 → 【高风险】

· 有方案但不够完善（如响应时间＞48小时） → 【中风险】

· 方案完善且响应时间≤24小时 → 【低风险】

【审查维度五：合规与信誉】（权重建议：20%）

规则5.1 - 法律诉讼记录

- 标准要求：无重大未决诉讼或强制执行记录

- 判定标准：

· 失信被执行人 → 【红线规则0.2，一票否决】

· 存在强制执行记录 → 【高风险】

· 存在未决诉讼（标的额＞注册资本30%） → 【高风险】

· 存在未决诉讼（标的额≤注册资本30%） → 【中风险】

· 无诉讼记录 → 【低风险】

规则5.2 - 行政处罚记录

- 标准要求：近2年内无重大行政处罚

- 判定标准：

· 存在质量/安全/环保类行政处罚 → 【高风险】

· 存在其他行政处罚 → 【中风险】

· 无处罚记录 → 【低风险】

规则5.3 - 企业信用状况（新增）

- 标准要求：企业信用状况良好，无严重失信记录

- 判定标准：

· 被列入严重失信主体名单 → 【高风险】

· 存在一般失信记录但已修复 → 【中风险】

· 信用良好 → 【低风险】

### 四、综合风险等级判定

1. 单项风险等级

每项审查规则均输出一个风险等级：高风险 / 中风险 / 低风险

2. 综合风险等级（取最高风险项）

- 【不建议准入】：存在任一线规则触发项 或 存在任一【高风险】项

- 【有条件准入】：无高风险项，但存在【中风险】项

- 【建议准入】：全部项为【低风险】
