# 供应商准入合规审查智能体 — 数据准备指南

> 文本类知识库的典型题：规则文档切块 + 资质参考 + 输出样例 + 待审档案。
> 评分关键：规则和资质"不可遗漏"，召回要精准到规则编号。

---

## 一、数据摸底（已实测核对）

| 文件 | 内容 | 入库角色 |
|---|---|---|
| 01_供应商准入审查基础规则.docx | 红线规则3条（0.1执照过期/0.2失信/0.3重大事故）+ 5维度16条规则（每条含标准要求+高/中/低判定标准）+ 综合判定（取最高风险项） | **核心规则库** |
| 02_供应商准入审查要求.docx | 审查范围6类材料、5维度权重、红线优先、输出格式字段（审查项/结果/风险等级/整改建议/审查依据） | 流程与输出规范 |
| 03_行业资质许可.docx | 仅3个行业：电子元器件(需ISO9001)、包装材料(**无需资质**)、IT运维(需ISO9001) | 规则1.4的比对依据 |
| 05_供应商准入审查意见样例.docx | 完整意见书模板：基本信息→红线检查表→逐项审查记录→综合结论→整改要求清单 | 输出格式参照 |
| 04_历史供应商准入档案/ | **仅2份**：电子元器件(广州恒信)、包装材料(杭州绿源) | 待审材料（测试输入） |

⚠️ 两个缺口：
1. 考试说明称测试用"**3份**待审档案"，练习包 04 文件夹里**只有 2 份**——考场注意核对，缺则找监考。
2. ⚠️ **电子元器件档案埋了红线**：营业执照"有效期至2025年11月（已过期）"→ 触发规则0.1一票否决 → 直接"不建议准入"。其余指标再好（注册资本1200万、准时率97%）也不能挽回。这是故意设计的陷阱，审查时必须**先查红线**。
3. 03 资质许可里**包装材料行业"无需具备资质证书"**——不能因缺资质证书误判高风险（对应包装材料档案"未提交行业经营许可证"是正确的）。

## 二、切块策略（按规则编号，一条一块）

- **01 基础规则**：按规则编号切，每块 = 一条完整规则（编号+标准要求+三档判定标准），如"规则1.4 行业资质许可…"。**红线规则 0.1/0.2/0.3 单独成块**（或单独文件），保证最先被召回。综合判定章节单独一块。
- **02 审查要求**：按"审查范围/审查维度/特殊要求/输出格式"四节切块。
- **03 行业资质许可**：按行业切 3 块（电子元器件/包装材料/IT运维），每块含"涵盖产品+应具备资质"。
- **05 意见样例**：不必细切，整篇入库作格式参照（或按"红线检查/逐项记录/综合结论/整改清单"切4块）。
- 打标签区分：`规则` / `要求` / `资质` / `样例` / `档案`，流程节点按标签定向检索。

## 三、入库后召回验证

| 验证问题 | 应召回 |
|---|---|
| 红线规则有哪些 | 0.1/0.2/0.3 三条，含"一票否决"表述 |
| 电子元器件行业需要什么资质 | ISO 9001；包装材料=无需资质 |
| 资产负债率80%是什么风险 | 规则2.3：70%-85%→中风险 |
| 审查意见要包含哪些字段 | 02 的输出格式节 + 05 样例结构 |

## 四、数据使用链路（流程搭建时的调用顺序）

```
待审档案文本 → ①红线规则库比对（触发即终止，输出不建议准入）
            → ②五维度16条逐条比对（每条给 符合/部分符合/不符合 + 高/中/低）
            → ③行业资质许可比对（仅规则1.4用）
            → ④按05样例格式组装意见书（结论=取最高风险项）
```
判定阈值全是文档里写死的数字（<3个月/≥500万/70%/≥3个案例/≥90%准时率），**比对计算放代码节点**，模型只做语义匹配，防止阈值口算出错。
