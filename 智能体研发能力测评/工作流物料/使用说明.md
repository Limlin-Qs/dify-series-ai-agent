## 二、导入后必做清单（每个文件，按顺序）

1. **导入**：平台 → 工作流/应用 → 导入 JSON。
2. **重新绑定知识库**：逐个点开「文本知识库搜索」「RAG重排器」节点，把知识库换成本题的（占位 ID：`0c65c3b8…` / `ad352453…` 是你原底稿的，必须换）。
3. **核对模型资源**：大模型节点用的资源（回答类 125/142、提取与意图类 129/149、重排 104/110）沿用你底稿。如果考场环境没有这些资源 ID，逐节点重新选模型。
4. **检查意图分支**：意图识别节点的分类出口按「意图1、意图2…默认」排列，点开确认每个出口连到的分支和你预期一致。
5. **跑 TC**：按考试包的测试用例逐条提问，对不上的先查知识库行格式（见第三节），再查提示词。

## 三、知识库行级格式规范（代码节点靠这些格式解析，格式错=答错）

核心经验：平台的「表格类型」文本知识库检索效果差，**统一把 Excel 转成"一行一条记录"的纯文本再入库**。方法：在 Excel 里加一列写公式拼接，下拉填充，复制结果列 → 粘贴为值到新表 → 另存为 txt（或放进 Word/txt 导入）。

### 1. 车辆题（语料/车辆运营里程与检修台账.xlsx）

「车辆里程台账」Sheet 从第 2 行起是数据，在新列输入：

```
="车号"&A2&"，"&B2&"，所属"&C2&"，当前运营里程"&D2&"万公里，投运日期"&TEXT(E2,"YYYY-MM-DD")&"，上次日检"&TEXT(F2,"YYYY-MM-DD")&"，上次双周检"&TEXT(G2,"YYYY-MM-DD")&"，上次三月检"&TEXT(H2,"YYYY-MM-DD")&"，上次年检"&TEXT(I2,"YYYY-MM-DD")&"，上次架修"&IF(J2="","从未架修",TEXT(J2,"YYYY-MM-DD"))&"，上次8万里程修"&IF(K2="","从未做过",TEXT(K2,"YYYY-MM-DD"))&"，上次40万里程修"&IF(L2="","从未做过",TEXT(L2,"YYYY-MM-DD"))&"，上次80万里程修"&IF(M2="","从未做过",TEXT(M2,"YYYY-MM-DD"))&"，车型"&N2
```

「检修股道占用台账」Sheet 同样从第 2 行起（判定节点靠"架修+股道+占用+日期"识别占用行）：

```
="段场："&B2&"，"&C2&"（"&D2&"），当前占用车号："&E2&"，占用"&TEXT(F2,"YYYY-MM-DD")&"至"&TEXT(G2,"YYYY-MM-DD")&"，未来30天预约："&H2&"，备注："&I2
```

规程类（均衡修规程、里程修规程、冲突规则、车辆检修规程与里程触发标准）：直接入库即可，判定常量已内嵌在代码节点里（日检1天/双周检14天/三月检90天/年检365天、架修5年或120万公里、里程修触发点8/40/80/120万±2%、CC003股道/CC005节假日/CC009周末、2026年法定节假日表），检索结果主要供大模型引用解释。

### 2. 防汛物资题（知识库/防汛物资明细汇总.xlsx）

从第 2 行起是数据，新列公式（**注意顺序是 站点→线路→部门**，这样代码节点才能正确截取站点名）：

```
="站点："&B2&"，线路："&A2&"，部门："&C2&"，防汛沙袋"&D2&"个，吸水膨胀袋"&E2&"个，防雨篷布"&F2&"块，救生衣"&G2&"件，安全绳"&H2&"根，防洪挡板"&I2&"组，L型轻型防洪挡板"&J2&"块，新型防淹挡板"&K2&"组，水动力全自动防洪闸"&L2&"组，大流量排水泵"&M2&"台，潜水泵"&O2&"台，自吸泵"&P2&"台"
```

已知行为：物资后勤中心的行（如"安顺车辆段1号线物资总库"）会按站点名里的"X号线"归到对应线路分组，属正常。「防汛物资总表汇总.xlsx」直接入库供汇总类问题检索。

### 3. 防汛风险题（知识库/附录3：两年清单.xlsx）

**第 5 行起才是数据**（前 4 行是标题/表头/说明），且风险描述、管控措施里有换行，必须用 SUBSTITUTE 去掉，否则一条记录被拆成多行、对比逻辑全错：

```
="【2024】"&B5&" | "&C5&" | "&D5&" | "&E5&" | "&F5&" | 风险描述："&SUBSTITUTE(SUBSTITUTE(G5,CHAR(13),""),CHAR(10),"；")&" | 管控措施："&SUBSTITUTE(SUBSTITUTE(H5,CHAR(13),""),CHAR(10),"；")&" | 责任人："&I5
```

2023 年文件把公式里的【2024】改成【2023】，两个文件的行**合并进同一个 txt** 入库（对比节点靠【年份】前缀区分）。

**已生成《防汛风险统计摘要.txt》**（就在本题知识库文件夹里），按练习文件逐行统计：2023 共 1258 个、2024 共 1486 个、分线路分等级分布、同比变化全在里面。把它和清单行文本一起入库，统计类问题（"哪条线最多""同比变化"）靠它回答，否则 top_k 检索盖不住上千条记录。⚠️ 考场下发的清单如果数据不同，这个摘要要重新统计（把两年 xlsx 发给我，我重算）。

### 4. 供应商题

规则类（01 基础规则、02 审查要求、03 行业资质许可）和「历史供应商准入档案」里的文件**直接入库**即可，无格式要求。链路是：检索 → 大模型逐项审查输出 JSON → 代码节点综合判定（红线一票否决；高风险→不建议准入；中→有条件；低→建议）→ 大模型写意见书。⚠️ 陷阱：电子元器件档案的营业执照**已过期**，属红线，TC 里答"建议准入"就是错的。

### 5. 施工题

《施工管理规定》.pdf 和「施工请销点台账.xls」直接入库，无代码节点。审核类问题由大模型按"符合/不符合/需补充"三选一输出。

### 6. 一线声音题

- **《一线声音层级路径.txt》已生成**（在本目录），由《1 智慧工地工程层级.xlsx》的 9239 个节点父子树展开成"全路径 | [id链] | 末端id | 末端名称"，直接入库。代码节点按地点词在检索结果里匹配路径行、取出 nodeIds 链。

- ⚠️ **类别映射是推测值**（咨询=1、建议=2、投诉=3）：练习包缺《一线声音类别.txt》《标签.txt》《输出格式.txt》3 个文件，考场上先找监考要，拿到后打开「表单组装」代码节点核对 type_map。
